代码里重点对照这两条线：

```text
POST → LogController.create → LogStore.insert
     → MySqlLogStore：EntityManager.persist，提交事务
     → MongoLogStore：LogMongoRepository.insert

GET  → LogController.query → LogStore.query
     → JPA条件分页 / MongoRepository条件分页
     → 相同的LogPage响应
```

查询的共同约定是：时间左闭右开 `[from,to)`，按 `createdAt、id` 降序，page从0开始。MongoDB中的 `id` 映射成 `_id`，这里使用字符串ULID。

我们直接使用 `@org.springframework.data.annotation.Id`；老师音频讲的 `@MongoId` 也是Mongo主键映射注解。主键是否自动生成还与字段类型、字段值和映射配置有关。本项目在Controller内明确生成ULID。

```promql
100 * (1 - irate(node_cpu_seconds_total{mode="idle"}[2s]))
node_load1
node_memory_MemAvailable_bytes / 1024 / 1024
100 * avg by (role) (irate(node_cpu_seconds_total{mode="iowait"}[2s]))

hikaricp_connections_active
hikaricp_connections_pending
```
