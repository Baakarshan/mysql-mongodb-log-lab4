# 报告排版说明

排版参照用户提供的《实验报告样例.pdf》。样例的PDF页面约为184×260毫米，本报告沿用此页面尺寸与单栏结构。

| 内容 | 本报告设置 | 对应样例特征 |
|---|---|---|
| 中文标题 | 黑体，14.05磅 | 左对齐黑体标题 |
| 作者 | 仿宋，12磅 | 标题下独立署名 |
| 中文摘要 | 楷体，9磅 | 摘要与正文区分字体 |
| 中文正文 | 宋体，9磅，约14.1磅行距 | 紧凑单栏正文 |
| 一级标题 | 黑体，10.45磅 | 编号与黑体标题 |
| 英文标题 | Times New Roman，10.45磅，加粗 | 英文标题独立成行 |
| 英文摘要 | Times New Roman，7.45磅 | 英文摘要小于正文 |
| 图注 | 8磅，居中 | 编号与图题置于图下 |

样例有效字号按PDF文字矩阵换算。中文字体使用本机黑体和楷体，宋体PDF导出映射至 Noto Serif CJK SC；具体字形随系统字体版本有所区别。Word保留各字体角色，PDF嵌入导出字体。

正文按“问题描述—实验环境与方法—实验设计—负载测试结果与分析—逐级压力测试结果与分析—总结”组织。低负载、转折附近和最高并发均直接展示JMeter趋势及百分位截图；同一次运行的两张图并排，两个实现上下对应。完整原图保存在 `screenshots/`，自绘汇总图用于全档位与资源比较。
